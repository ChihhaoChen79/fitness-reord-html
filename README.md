# 健身訓練追蹤 App

一個純前端、純本地儲存的健身訓練追蹤 Web App。沒有後端、沒有帳號、沒有雲端同步——所有資料都存在你自己的瀏覽器裡，介面全為正體中文，主要為 iOS Safari（加入主畫面使用）設計，但任何現代瀏覽器都能開啟使用。

## 功能

- **動作庫**：內建 67 個常見健身房動作（胸/背/腿/肩/手臂/核心/有氧），也可以自訂動作。找不到圖片或沒網路時自動顯示黑色佔位區塊。
- **菜單（Routine）**：自訂菜單，設定每個動作的組數、重量/次數（或距離/時間）、單手雙手變化、備註。
- **訓練記錄**：
  - 從既有菜單開始，或直接開始空白訓練。
  - 記錄過程中會自動暫存草稿，中途離開重開也不會遺失。
  - 完成訓練後才正式寫入資料庫，並顯示隨機激勵語。
  - 若用菜單訓練但內容有改動，結束時會問是否要更新菜單；空白訓練完成後會問是否存成新菜單。
  - **補記錄過去的訓練**：在「紀錄」頁可以手動選日期/時間/時長，回填之前忘記記錄的訓練。
- **紀錄**：依月份檢視所有訓練，可手動編輯或刪除單筆紀錄。
- **統計**：訓練次數、部位分佈、動作最大重量趨勢、訓練量趨勢、體重/體脂趨勢、本月回顧。
- **設定**：公制/英制單位切換、淺色/深色/自動主題、自訂標籤管理。
- **備份**：一鍵匯出/匯入 JSON，換裝置或清除瀏覽器資料前記得備份。

## 使用方式

### 方法一：GitHub Pages（推薦，可加入主畫面變成全螢幕 App）

1. 到這個 repo 的 **Settings → Pages**，Source 選 `Deploy from a branch`，branch 選 `main`、資料夾選 `/(root)`，儲存。
   > 若 repo 是 Private，免費方案的 GitHub Pages 需要先把 repo 改成 Public 才能用。
2. 等 1–2 分鐘後，會出現一個網址（例如 `https://<你的帳號>.github.io/fitness-reord-html/`）。
3. 用 iPhone 的 **Safari** 打開這個網址。
4. 點下方分享圖示 → **加入主畫面**，之後就有一個獨立的 App 圖示可以全螢幕使用。

### 方法二：本機直接開啟

下載整個資料夾（`index.html` 和 `vendor/` 要放在同一層），用瀏覽器打開 `index.html` 即可。統計圖表需要 `vendor/chart.umd.js` 在旁邊才能正常運作。

## 資料儲存與備份

所有資料都存在瀏覽器本機的 IndexedDB / localStorage，**沒有任何雲端同步**。這代表：

- 清除瀏覽器資料、換手機、或重灌 App 都會遺失資料。
- 請養成定期到「我的」→「匯出備份」下載 JSON 檔的習慣。
- 換裝置或需要救回資料時，用「我的」→「匯入備份」讀取先前匯出的 JSON 即可還原。

## 技術棧

- 純原生 JavaScript（無框架、無建置流程），單一 `index.html` 檔案
- IndexedDB（動作庫/菜單/訓練紀錄/身體指標/標籤）+ localStorage（設定、訓練草稿）
- [Chart.js](https://www.chartjs.org/)（本地內建於 `vendor/chart.umd.js`，不依賴 CDN，離線也能顯示圖表）
- 自訂輕量 CSS 工具類別（取代 Tailwind CDN，避免執行時需要網路連線）

## 專案結構

```
.
├── index.html          # 整個 App（畫面、邏輯、樣式全部在這一個檔案）
└── vendor/
    └── chart.umd.js    # 本地內建的 Chart.js，供統計頁圖表使用
```
